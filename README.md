# 糖果屋 / Candy House

Diting 官方 Neo-Brutalism 主题：高饱和糖果色、粗黑边框、硬阴影。

- short：`neobrutalism`
- 版本：1.0.0
- 适用：Diting（`/themes/neobrutalism/`）

## 安装

在 Diting 后台「设置 → 主题 → 市场」中安装，或直接解压本主题包到数据目录的 `themes/neobrutalism/`。

## 目录

```
diting-theme.json   # 主题清单（short / name / version / author）
manifest.json       # 旧版兼容清单
index.html          # 页面入口
style.css           # 样式
neobrutalism.js     # 交互与数据请求
preview.svg         # 市场预览图
```

## 发布

Release 资源 `neobrutalism-<version>.zip` 的根目录必须包含 `diting-theme.json`，官方市场据此校验并收录。
